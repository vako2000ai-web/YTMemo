# Мемо — автоматическая игра для YouTube

52 карточки, 26 пар флагов. В каждом раунде на экране появляется «Пожалуйста, выберите два номера карточек», а голос говорит «Пожалуйста, укажите две карточки». После нажатия «Запустить игру» игра ведётся автоматически.

1. На ответ отводится 15 секунд.
2. Первое корректное сообщение в подключённом YouTube-чате выбирает две карточки. Формат: `7 24`, `7, 24` или `7 и 24`. Нужны два разных номера от 1 до 52, ещё не собранные в пары.
3. Если ответа нет, робот случайно выбирает две оставшиеся карточки. Робот не использует скрытые флаги для выбора.
4. Пара приносит одно очко лично автору сообщения или роботу. Каждый зритель определяется по стабильному ID YouTube-канала: одинаковые имена не объединяются, изменение имени не сбрасывает счёт.
5. Несовпавшие карточки закрываются на прежних местах. После каждого результата автоматически начинается новый раунд.
6. После 26 пар показывается итоговый рейтинг. На основном экране видны робот и пять лидирующих зрителей; в результатах — все участники.

## Настройка

Все параметры задаются в `config.json`. После изменения файла перезапустите сервер.

| Параметр | Назначение | По умолчанию |
| --- | --- | --- |
| `server.host` | Адрес прослушивания | `0.0.0.0` |
| `server.port` | Порт сервера | `3000` |
| `youtube.videoUrl` | Ссылка на активный эфир или ID видео | Пусто, можно подключить в интерфейсе |
| `youtube.apiKey` | Ключ YouTube Data API v3 | Пусто |
| `youtube.retrySeconds` | Пауза между попытками после ошибки API | `15` |
| `game.waitSeconds` | Ожидание зрителей | `15` |
| `game.revealSeconds` | Показ открытых карточек | `3` |
| `game.sounds` | Звуковые сигналы | `true` |
| `game.voice` | Голосовая подсказка | `true` |
| `game.streamMode` | Сразу скрыть служебные панели для эфира | `false` |
| `speech.language` | Язык системного голоса | `ru-RU` |
| `speech.rate` | Скорость речи | `0.95` |

Ключ также можно задать переменной окружения `YOUTUBE_API_KEY`, она имеет приоритет над файлом. `PORT` имеет приоритет над `server.port`. Файл настроек и серверные исходники не доступны через веб-сервер; API настроек выдаёт только публичные параметры без ключа. Не публикуйте заполненный ключом файл.

Изменения звука, голоса и времени показа в интерфейсе сохраняются в этом браузере и имеют приоритет над соответствующими значениями файла. Счёт текущей партии хранится в памяти страницы: перезагрузка начинает новую партию.

## Запуск

Нужен Node.js 18 или новее. Внешние зависимости не требуются.

```sh
# При первом запуске после клонирования репозитория:
cp config.example.json config.json
npm start
```

Откройте http://localhost:3000. Подключите чат до запуска игры. Нажмите «Запустить игру» один раз — это также даёт браузеру разрешение на воспроизведение голоса. Дальше клики ведущего не нужны.

Без ссылки или ключа игра работает с ходами робота. В раскрывающемся блоке «Проверка ответа зрителя без эфира» можно вводить имя, ID зрителя и два номера, чтобы проверить личный счёт.

## YouTube и OBS

Создайте ключ в Google Cloud Console и включите **YouTube Data API v3** в этом проекте. Укажите ключ и ссылку на эфир в настройках. Трансляция должна быть запущена, а чат доступен. Сервер читает чат через официальный YouTube API и соблюдает возвращаемый сервисом интервал опроса. Старые сообщения при первом подключении не участвуют в игре. При ошибке подключения робот продолжает ходить.

Опрос имеет задержку: принимаются сообщения, полученные приложением до конца отсчёта и опубликованные в текущем раунде. Ответ, отправленный в самые последние секунды, может прийти после выбора робота. Частые запросы расходуют квоту проекта YouTube API; после исчерпания квоты интерфейс показывает ошибку.

Добавьте окно браузера в OBS через «Захват окна», включите захват звука браузера и «Режим стрима». Синтез речи использует голос браузера/ОС; для русской озвучки должен быть доступен русский голос. Без него установите русский голос в ОС. Игра не выполняет вход в Google и не отправляет сообщения в чат.

Тесты охватывают колоду, автоматическую механику, личные счета, донат-бонусы, темы, OAuth-вход, обновление токенов, историю и повторы DonationAlerts, а также адаптер YouTube на имитированных ответах API. Подключение к настоящему эфиру проверяется после указания ссылки и ключа.

## Донат-бонусы

- **От 1 USD:** открывается одна карта, а её парная карточка подсвечивается, оставаясь рубашкой вверх. В сообщении к донату укажите `карта 12`. Без номера выбирается случайная оставшаяся карта. Если указанная карта уже собрана в пару, выбирается другая оставшаяся. По умолчанию подсказка показывается 8 секунд, затем карты возвращаются в обычное состояние и начинается новый 15-секундный раунд. Подсказка сама по себе не начисляет очко.
- **От 5 USD:** имя появляется на рубашках всех карт до конца текущей партии. Если донатеров несколько, их имена чередуются каждые 5 секунд. Новая партия очищает уже показанные имена.
- **От 9,99 USD:** все 52 карточки отображаются лицом вверх на 8 секунд. Выбор карт и обычный раунд на это время приостанавливаются. Затем несобранные карты закрываются на прежних местах и начинается новый 15-секундный раунд. Уже найденные пары и счёт сохраняются; показ не начисляет очки. Если другая пара или подсказка уже открыта, бонус ждёт своей очереди.
- Автоматически выбирается один бонус по наибольшему достигнутому порогу: от 1 USD — подсказка, от 5 USD — имя, от 9,99 USD — открытие всех карт. Адаптер может явно указать `reward: "hint"`, `"name"` или `"revealAll"` при достаточной сумме.
- Подсказки, поступившие во время открытия другой пары или на паузе, становятся в очередь. Бонусы, пришедшие после завершения игры, и неиспользованные подсказки переносятся в следующую партию в этой вкладке.
- В разделе «Управление донат-бонусами» есть **тестовый донат**. Он не списывает деньги и не проверяет реальный платёж. Управление скрывается в режиме стрима.

### Параметры `config.json`

| Параметр | Значение по умолчанию |
| --- | --- |
| `donations.enabled` | `false` — реальный вход платежей выключен |
| `donations.currency` | `USD` — принимается только указанная валюта, без автоматической конвертации |
| `donations.hintAmount` | `1` — минимальная сумма за подсказку |
| `donations.nameAmount` | `5` — минимальная сумма за имя |
| `donations.revealAllAmount` | `9.99` — минимальная сумма за открытие всех карт |
| `donations.hintSeconds` | `8` |
| `donations.revealAllSeconds` | `8` — время показа всех карт |
| `donations.nameRotationSeconds` | `5` |
| `donations.paymentUrl` | Пусто — ссылка на вашу страницу донатов; при заполнении появляется кнопка поддержки |
| `donations.webhookSecret` | Пусто — секрет подписи входящих подтверждённых платежей |
| `donations.overlayToken` | Пусто — отдельный токен для чтения бонусов игровым окном |
| `theme` | `classic` — тема рубашек |

`DONATION_WEBHOOK_SECRET` и `DONATION_OVERLAY_TOKEN` имеют приоритет над файлом. Секрет подписи остаётся только у сервера и доверенного адаптера донат-сервиса. Токен чтения вводится в интерфейсе ведущего, хранится в памяти вкладки и не записывается в localStorage. Секреты не попадают в публичный API настроек.

### Прямое подключение DonationAlerts

Игра получает новые донаты через официальный [DonationAlerts API](https://www.donationalerts.com/apidoc), `GET /api/v1/alerts/donations`. Право доступа — `oauth-donation-index`. Режим DonationAlerts выбран в настройках по умолчанию; реальный приём включается после заполнения параметров.

1. Войдите в DonationAlerts и [зарегистрируйте OAuth-приложение](https://www.donationalerts.com/application/clients). Скопируйте **Client ID** и **Client Secret** в `donationAlerts.clientId` и `donationAlerts.clientSecret`.
2. В приложении DonationAlerts укажите Redirect URI **точно** как в `donationAlerts.redirectUrl`: по умолчанию `http://localhost:3000/api/donations/donationalerts/callback`. Для удалённого сервера используйте свой HTTPS-домен с тем же путём. Открывайте игру по этому же адресу/домену: `localhost` и `127.0.0.1` являются разными адресами для cookie авторизации.
3. В `config.json` оставьте `donations.provider: "donationalerts"`, задайте `donations.enabled: true` и отдельный длинный случайный `donations.overlayToken`. Укажите вашу ссылку оплаты в `donations.paymentUrl`, например `https://www.donationalerts.com/r/ВАШЕ_ИМЯ`.
4. Перезапустите сервер. В игре раскройте «Управление донат-бонусами», введите `overlayToken` и нажмите **«Войти в DonationAlerts»**. В открывшейся вкладке разрешите чтение донатов. Вход запускает подключение бонусов автоматически; после подтверждения вкладку авторизации можно закрыть.
5. Дождитесь статуса «DonationAlerts подключён». Первая загрузка пропускает старую историю. Теперь новые донаты будут выдавать бонусы автоматически. Затем запустите игру и включите режим стрима.

Не требуется создавать промежуточный адаптер или принимать внешние webhook-запросы: приложение само опрашивает DonationAlerts. Запросы идут только пока игровое окно подключено к бонусам, по умолчанию каждые 5 секунд; доставка в интерфейс занимает обычно до 6 секунд, при ошибках — дольше. Ограничения частоты API обрабатываются с ожиданием повторной попытки. Донаты, поступившие во время текущего открытия карт, получают подсказку после завершения хода.

API возвращает сумму и валюту платежа. **Валюта доната должна совпадать с `donations.currency`.** Для USD оставьте цены `1`, `5` и `9.99`. Если принимаете RUB, задайте `currency: "RUB"` и свои рублёвые цены; автоматической конвертации курсов нет. `карта 12` в текстовом сообщении выбирает карту для подсказки. Аудиосообщение не разбирается — карта выбирается случайно.

Если OAuth access token уже получен с правом `oauth-donation-index`, можно вместо входа через кнопку заполнить `donationAlerts.accessToken` и нажать **«Подключить реальные донаты»**. Секретный токен виджета DonationAlerts не заменяет OAuth access token.

| Параметр | Назначение |
| --- | --- |
| `donationAlerts.clientId` | ID зарегистрированного OAuth-приложения, строкой |
| `donationAlerts.clientSecret` | Секрет OAuth-приложения |
| `donationAlerts.redirectUrl` | Адрес callback игры, совпадающий с URI приложения |
| `donationAlerts.accessToken` | Необязательный готовый OAuth access token |
| `donationAlerts.refreshToken` | Необязательный готовый refresh token |
| `donationAlerts.pollSeconds` | Интервал опроса, по умолчанию `5` секунд |
| `donationAlerts.retrySeconds` | Повтор после ошибки, по умолчанию `30` секунд |
| `donationAlerts.maxPages` | Максимум страниц новых донатов за один опрос, по умолчанию `20` |

Переменные `DONATIONALERTS_CLIENT_ID`, `DONATIONALERTS_CLIENT_SECRET`, `DONATIONALERTS_ACCESS_TOKEN`, `DONATIONALERTS_REFRESH_TOKEN` имеют приоритет над соответствующими полями файла. OAuth access token и refresh token сохраняются на сервере в приватном `donationalerts-auth.json` с доступом только владельцу файла. При истечении токена приложение обновляет его автоматически, если доступны refresh token и client credentials. Токены не передаются в игровой браузер и не выдаются публичным API.

Приватный `donationalerts-state.json` хранит последний ID истории, а `donation-ledger.json` предотвращает повторную выдачу одного платежа после повторного опроса или перезапуска. Не удаляйте эти файлы работающей интеграции. При смене аккаунта выполните новый OAuth-вход через кнопку: история нового подключения будет пропущена. Не подключайте один и тот же экземпляр одновременно к разным аккаунтам.

Текущее оформление партии и неиспользованные бонусы остаются в памяти вкладки. После её перезагрузки нужно снова ввести токен подключения; первое чтение начинает поток новых событий без воспроизведения истории. Включайте приём платежей после подключения игрового окна. Проверки на имитированных ответах DonationAlerts проведены; авторизация и получение донатов настоящего аккаунта проверяются после заполнения ваших OAuth-параметров.

### Универсальный подписанный вход

Для другого источника можно выбрать `donations.provider: "webhook"`. Адаптер должен сначала получить подтверждённый платёж от сервиса, затем отправить `POST /api/donations/webhook` с JSON:

```json
{
  "id": "уникальный-id-платежа-из-сервиса",
  "name": "Имя донатера",
  "amount": 1,
  "currency": "USD",
  "reward": "hint",
  "card": 12
}
```

Заголовок `X-Donation-Signature` содержит HMAC-SHA256 точных байтов тела, подписанный `donations.webhookSecret`. Для имени передайте `amount: 5`, `reward: "name"`; для открытия всех карт — `amount: 9.99`, `reward: "revealAll"`. Чтение игровым окном требует отдельного `donations.overlayToken`. Секрет подписи и токен чтения должны различаться. Для режима DonationAlerts этот вход и секрет подписи не нужны.

## Праздничные рубашки

Доступны шесть тем: классика, Новый год, Хэллоуин, Рождество, День влюблённых и Пасха. Тема выбирается через список «Рубашки» над полем либо параметр `theme` в настройках:

- `classic`
- `newyear`
- `halloween`
- `christmas`
- `valentine`
- `easter`
- `auto` — сезонный выбор по дате браузера; Пасха выбирается вручную.

Каждая тема имеет свою иллюстрацию, цвета и узор. Смена темы не перемешивает карты и не меняет счёт. Выбор в интерфейсе сохраняется в этом браузере и имеет приоритет над файлом настроек.

Для отдельного экземпляра сервера можно использовать `MEMO_CONFIG_PATH` (путь к своему JSON) и `DONATION_LEDGER_PATH` (путь к журналу платежей).

`DONATIONALERTS_AUTH_PATH` и `DONATIONALERTS_STATE_PATH` задают отдельные пути для приватных OAuth-токенов и позиции истории.
